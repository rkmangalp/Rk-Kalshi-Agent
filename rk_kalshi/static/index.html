Paper session

Start paper trading

Set a paper bankroll, then Start. Paper-trades Kalshi Bitcoin buy and sell (YES contracts) and optional live tennis. Optionally lock tennis to one pasted Kalshi match. This is simulated cash — the UI cannot place live Kalshi or exchange orders. can_size_up stays locked. Stop ends polling. Clear wipes the local paper session (fills, P&L, log, selected match) — not a live Kalshi account.

Tennis contract

Choose a match to paper-trade

If a match is set, paper tennis uses only that match’s contracts — not every open book. Paste a Kalshi tennis URL or pick a listed event.

No match selected — tennis can scan the full universe.

Examples: https://kalshi.com/markets/kxatpmatch/atp-tennis-match/kxatpmatch-26sep06cerblo · https://kalshi.com/markets/kxwtamatch/wta-tennis-match/kxwtamatch-26mar29vekgor · ticker KXATPMATCH-26SEP06CERBLO

Clear resets this local paper book only. It does not cancel or touch live Kalshi orders.
